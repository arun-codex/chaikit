# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 1.0.x | Yes |

## Reporting a Vulnerability

If you discover a security vulnerability in ChaiKit, please report it privately:

- Submit a private vulnerability advisory on GitHub.
- Or email: security@chaikit.org

Please provide detailed reproduction steps. We will acknowledge receipt within 48 hours and coordinate a fix prior to public disclosure.
