# Changelog

All notable changes to ChaiKit are documented in this file.

## [1.0.0] - 2026-11-17

### Added
- Standards-based `<chai-support>` Web Component with Shadow DOM style encapsulation.
- Core validation, exact integer paise arithmetic, and NPCI UPI URI generation.
- Client-side high-contrast SVG QR code generation without remote API calls.
- Four default chai contribution tiers (Cutting, Kadak, Tandoori Kulhad, Premium Cup) with custom vector illustrations.
- Support for custom contribution amounts with real-time numeric validation.
- Five built-in themes: `classic`, `dark`, `cream`, `minimal`, and `auto`.
- Three embedding modes: Floating launcher, Inline card (`position="inline"`), and Headless trigger.
- Full keyboard navigation, focus trap, and screen-reader announcements (WCAG 2.2 AA).
- `@chaikit/react` wrapper with full TypeScript support, ref forwarding, and SSR safety.
- Comprehensive documentation and integration examples for Vanilla HTML, React, Next.js, Vue, and static sites.
