HTML Embed Snippet

Add this snippet before </body> on any static site, WordPress, Hugo, or Jekyll page: 

<!-- 1. Include ChaiKit script -->
<script defer src="https://cdn.jsdelivr.net/npm/@chaikit/widget@1.0.0/dist/chaikit.iife.js"></script>

<!-- 2. Configure your creator widget -->
<chai-support
  creator-name="Your Name"
  upi-id="yourname@bank"
  theme="auto"
  position="bottom-right"
></chai-support>
